Politique de confidentialité

Informations sur le fonctionnement du site personnel heyadri.online.

1. Présentation du site

Ce site est un espace personnel présentant un profil, des liens vers des réseaux sociaux et un lecteur musical. Pour contacter son responsable, vous pouvez utiliser les liens de contact disponibles sur la page d'accueil.

2. Données enregistrées sur votre appareil

Le site utilise le stockage local du navigateur (localStorage) pour mémoriser un compteur de visites sur cet appareil, sous la clé visits. Ce compteur est local : le code du site ne l'envoie pas à un serveur. Vous pouvez le supprimer en effaçant les données du site dans les paramètres de votre navigateur.

3. Services externes

Le profil et le statut Discord affichés sur la page d'accueil sont récupérés par l'intermédiaire de l'API Lanyard. Certaines icônes sont chargées depuis des services externes, notamment Flaticon et des ressources tierces. Ces services peuvent recevoir des informations techniques, comme votre adresse IP, lorsqu'une ressource est demandée.

Les liens vers les réseaux sociaux vous redirigent vers leurs plateformes respectives, qui appliquent leurs propres règles de confidentialité.

4. Musique

Les fichiers musicaux du lecteur sont servis depuis ce site. La lecture automatique peut être bloquée par votre navigateur.

5. Hébergement et données techniques

Le site est hébergé via GitHub Pages. L'hébergeur et les fournisseurs techniques peuvent traiter certaines données liées aux requêtes, notamment à des fins de fonctionnement et de sécurité. Pour plus d'informations, consultez la déclaration de confidentialité GitHub.

6. Vos questions

Pour une question relative à la confidentialité de ce site, vous pouvez contacter le responsable à l'aide des moyens indiqués sur la page d'accueil.
